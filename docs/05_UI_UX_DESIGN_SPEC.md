## 1. デザイン理念

### 1.1 基本原則

**Material Design から：**
- ✅ **マテリアル性** — 画面に階層感を持たせる（影・奥行き）
- ✅ **モーション** — ユーザーアクションに対する応答をアニメーション化
- ✅ **色彩システム** — 一貫した配色で統一感を出す

**Human Interface Design から：**
- ✅ **シンプルさ** — 不要な要素を削ぎ落とす
- ✅ **明確さ** — ユーザーが迷わない設計
- ✅ **親しみやすさ** — 学生にとって使いやすい

## 5. コンポーネント設計

### 5.1 ボタン

**サイズ:** 高さ 48px（タップ目標: 最小 44px）  
**パディング:** 左右 16px  
**コーナー半径:** 8px  
**アニメーション:** タップ時に 0.2s の背景色変化

**3つのバリエーション：**

```
【Primary ボタン】
  背景: インディゴ (#6366F1)
  テキスト: ホワイト
  用途: 主要アクション（送信、保存、ログイン）

【Secondary ボタン】
  背景: グレー (#E5E7EB)
  テキスト: ダークグレー (#1F2937)
  用途: キャンセル、補助アクション

【Tertiary ボタン】
  背景: 透過
  テキスト: インディゴ (#6366F1)
  ボーダー: インディゴ 1px
  用途: テキストのみの軽いアクション
```

## 6. アニメーション・モーション

### 6.1 タイミング

| アクション | 時間 | 用途 |
| --- | --- | --- |
| ボタンタップ | 0.2s | ユーザー操作への即座の反応 |
| 画面遷移 | 0.3s | 画面切り替え |
| モーダル出現 | 0.3s | ダイアログ表示 |
| 絵文字降下 | 1.0s | 完了セレモニー |

### 6.2 イージング

- **即座な反応：** `ease-out` （最初は速く、後で遅くなる）
- **滑らかな移動：** `ease-in-out` （自然な加減速）
- **登場・退場：** `cubic-bezier(0.34, 1.56, 0.64, 1)` （弾むような動き）

## 9. アクセシビリティ

### 9.1 コントラスト比

**WCAG AA 基準（最小 4.5:1）を遵守**

```
テキスト（黒）vs 背景（白）: 21:1 ✅
テキスト（グレー）vs 背景（白）: 7:1 ✅
テキスト（インディゴ）vs 背景（白）: 4.5:1 ✅
```

### 9.2 タッチターゲット

- **最小サイズ：** 44×44px
- **ボタン：** 48×48px 推奨
- **アイコン：** 24×24px 最小

### 9.3 キーボード操作

- **Tab キー：** フォーム、ボタンを順序よく移動
- **Enter キー：** ボタン・リンクを実行
- **Esc キー：** ダイアログを閉じる
- **フォーカスインジケータ：** 2px のアウトライン表示

## 11. レスポンシブ対応

### 11.1 ブレークポイント

| デバイス | 幅 | レイアウト |
| --- | --- | --- |
| モバイル | < 640px | シングルカラム、フルスクリーン |
| タブレット | 640px ～ 1024px | 2カラム（可選）、サイドバー |
| デスクトップ | > 1024px | 3カラム、ナビゲーション固定 |

### 11.2 モバイル優先設計

**MVP はモバイル 100%。デスクトップは PC ブラウザでのスケーリングで対応。**

```css
/* モバイル：フルスクリーン */
.container {
  width: 100%;
  padding: 16px;
}

/* デスクトップ */
@media (min-width: 1024px) {
  .container {
    max-width: 800px;
    margin: 0 auto;
  }
}
```

## 12. Material Design と HIG の使い分け

### 12.1 Material Design 採用部分

✅ **マテリアル性**（影・奥行き感）
✅ **色彩システム**（統一された配色）
✅ **モーション**（反応性のあるアニメーション）

### 12.2 HIG 採用部分

✅ **シンプルさ**（余分な要素を削ぎ落とす）
✅ **明確さ**（ユーザーが迷わない）
✅ **親しみやすさ**（親切な UI）

### 12.3 折衷案

例）ボタン設計
- **Material:** 3つのバリエーション（Primary, Secondary, Tertiary）
- **HIG:** シンプルに、本当に必要なものだけ
- **折衷案：** 2つのバリエーション（Primary, Secondary）に絞る
